# 设置音效

《DELTARUNE Chapter 5》的 `obj_darkcontroller` 用 `snd_menumove` 播放选项移动声，用 `snd_select` 播放确认声。
在本地游戏数据中，两者位于音频组 1，编号分别为 42 和 55。这里使用同版已导出的原始 WAV，格式为 44.1 kHz、16 位单声道 PCM。
[原始音效文件](https://github.com/Kris1225-hash/deltarune-chapt5-decomp/tree/8cd29bcd24697f73c9c6f25e66526a9c41df1018/sounds)
